# HTML Codespaces Starter Template

Use this template to begin your HTML/CSS team project in GitHub Codespaces.

## Files and Folders

- `index.html` — Main webpage
- `css/style.css` — Stylesheet
- `images/` — Store website images here

## Team Lead: Create the Team Repository

1. Open the class template repository on GitHub.
2. Click **Use this template** and select **Create a new repository**.
3. Select the organization your teacher has instructed you to use.
4. Name the repository using the naming format provided by your teacher.
5. Create the repository.

## Team Lead: Invite Your Team Members

After the team repository has been created, the Team Lead must give each team member access.

1. Open your team's repository on GitHub.
2. Click **Settings** near the top of the repository.
3. In the left menu, locate **Collaborators and teams** or **Collaborators** under **Access**.
4. Click **Add people** or **Add collaborator**.
5. Search for a team member using their **GitHub username**.
6. Select the correct student and send the invitation.
7. Repeat these steps until **every team member has been invited**.
8. Tell your team members to check GitHub and **accept the repository invitation**.

> **Important:** Team members cannot work in the team repository until they have access. Make sure everyone accepts their invitation before beginning the project.

## Team Members: Join the Repository

1. Sign in to GitHub.
2. Accept the repository invitation from your Team Lead if one was sent.
3. Open your team's repository.
4. Click **Code**.
5. Select the **Codespaces** tab.
6. Create or open your Codespace for the team repository.

## Getting Started in Codespaces

1. Open `index.html`.
2. Replace the placeholder content with your team's content.
3. Add CSS rules to `css/style.css`.
4. Save website images inside the `images` folder.
5. Preview and test the webpage as you work.

## Working as a Team

Everyone is working from the same GitHub repository. Before beginning new work, make sure you have the latest version of the team's files. Use the **Source Control** tools in Codespaces to commit and sync your changes regularly.

### Before You Start Working

- Make sure your Codespace has the latest team changes.
- Communicate with your teammates about which files or sections you are editing.
- Avoid having multiple students make major changes to the same section at the same time when possible.

### After You Finish a Task

1. Save your files.
2. Open **Source Control** in Codespaces.
3. Review the files you changed.
4. Enter a short commit message describing your work.
5. Commit your changes.
6. Sync/push your changes to the team repository.

## Reminder

**Commit and sync your work regularly.** Do not wait until the end of class to upload all of your changes.
